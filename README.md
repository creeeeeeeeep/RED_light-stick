# 레드 응원봉

흔들면 치지직 채팅에 이모티콘이 쌓이고, 버튼을 누르면 전송되는 응원봉.
RED레드 채널 팬들에게 **무상 배포**할 목적으로 만든다 (판매·광고 없음).

```
봉(ESP32-S3) ──HTTP POST──▶ 중계 서버 ──WebSocket──▶ 크롬 확장 ──▶ 치지직 채팅
```

중계 서버는 **팬 각자의 컴퓨터에서** 돈다. 봉도 브라우저도 같은 집 안에 있으니
바깥에 서버를 둘 이유가 없다. 호스팅 비용도, 집 IP 노출도, 스트리머 PC 가 꺼지면
전부 멈추는 문제도 없다. 대신 응원봉을 쓰는 동안 팬의 컴퓨터가 켜져 있어야 한다.

## 구성

| 폴더 | 무엇 | 언어 |
|---|---|---|
| `firmware/` | 봉 펌웨어 — 모션 인식, LED, WiFi, OTA | C (ESP-IDF v5.5) |
| `server/` | 중계 서버 — **팬의 PC 에서 돈다** | Python (aiohttp) |
| `extension/` | 크롬 확장 — 채팅에 이모티콘을 넣는다 | JS (Manifest V3) |
| `docs/` | 설치 안내, 작업 기록, 치지직 조사 자료 | 문서 |

하드웨어는 **Waveshare ESP32-S3-Matrix** (8x8 WS2812 + QMI8658 6축 IMU) 하나로,
LED와 IMU가 보드에 이미 붙어 있어 **전송 버튼만 납땜하면 된다** (GPIO2 + GND).

## 어떻게 동작하나

**모션 인식.** 가속도를 중력 방향과 그에 수직인 성분으로 나눠 좌우 흔들기 /
위아래 찍기 / 격하게 흔들기를 가른다. 보드를 어느 방향으로 넣든 중력을 매
순간 추정하므로 판정이 같다.

**이모티콘 입력.** 치지직은 채팅 입력창에 직접 넣는 것을 막는다. 그래서 확장이
**이모티콘 피커를 화면에서 감춘 채로 열어 해당 버튼을 대신 클릭한다.** 치지직이
보기에는 사용자가 직접 고른 것과 구별되지 않는다.

**전송은 사람이.** 흔들면 쌓이기만 하고, 물리 버튼을 눌러야 채팅에 나간다.
"사람의 1회 조작 = 채팅 1건" 을 지키기 위한 구조이며, 자동·주기 전송은 넣지 않는다.

**방(room) 개념이 없다.** 서버가 팬마다 자기 컴퓨터에서 도니 나눠 쓸 상대가
없기 때문이다. 봉 이벤트는 붙어 있는 확장 전부에게 간다. 확장은 `localhost`
로만 붙어서 같은 컴퓨터인 것이 증명되고, 붙으면 서버가 열쇠를 알려준다.
봉은 LAN 을 건너오므로 그 열쇠를 실어야 하는데, 설정 페이지가 대신 써넣는다.

## 시작하기

```bash
# 1. 서버 — 더블클릭으로도 된다: server/응원봉_서버_켜기.bat
cd server && py server.py

# 2. 확장 — chrome://extensions 에서 "압축해제된 확장 프로그램 로드"
#    → extension 폴더 선택

# 3. 펌웨어
cd firmware && .\crown.bat        # 인자 없이 실행하면 메뉴가 뜬다
```

`.bat` 은 파이썬과 aiohttp 를 확인해 없을 때만 설치하고 서버를 띄운다.
팬이 터미널을 열 일이 없게 하려고 둔 것이다.

봉을 굽고 나면 확장의 **옵션 페이지**를 열어 WiFi를 넣는다. 서버 주소와 열쇠는
서버가 알려주므로 직접 입력할 것이 없다 — 팬이 넣는 것은 WiFi 비밀번호뿐이다.

자세한 것은 [`firmware/README.md`](firmware/README.md) 와
[`docs/작업일지.md`](docs/작업일지.md) 를 보면 된다. 작업일지에는 **밟았던 함정**이
정리돼 있어서 같은 데서 두 번 막히지 않는다.

## 감수한 것

- **응원봉을 쓰는 동안 팬의 컴퓨터가 켜져 있어야 한다.** 서버가 거기서 돌기
  때문이다. 그 대가로 호스팅·도메인·집 IP 노출·상시 가동이 전부 사라졌다.
- **펌웨어 갱신은 손으로 한다.** OTA 코드는 남아 있지만 각자 서버에는 받아올
  펌웨어가 없어 조용히 넘어간다. 새 버전은 파일을 받아 다시 구우면 된다.

## 아직 안 된 것

- **확장이 웹스토어에 없음** — 지금은 개발자 모드로 설치해야 하고, 크롬이
  켤 때마다 경고를 띄운다. 등록에는 1회 5달러와 심사가 필요하다.
- **임계값 튜닝** — 지금 값은 맨보드를 손으로 흔든 데이터로 맞춘 것이라,
  크라운을 달면 질량과 길이가 달라져 다시 잡아야 한다.
- **조작 방식 변경 예정** — 봉이 굴러다니기만 해도 모션으로 잡혀 채팅이
  지저분해진다. 데모 봉 조립 후 "버튼을 누르고 있는 동안만" 으로 바꾼다.

## 설정 파일

`server/config.json` 은 저장소에 없다. 서버를 처음 켜면 자동으로 만들어지고,
그때 **열쇠도 함께 생성된다.** 손댈 일이 없다.

모션과 이모티콘의 짝을 바꾸고 싶을 때만 열어보면 된다.

```json
{
  "token": "(서버가 만든다)",
  "motions": {
    "SWAY_LR":  "redredMinidance1",
    "PUMP_UD":  "redredLight",
    "VIGOROUS": "redredLight5"
  }
}
```

**열쇠는 공개하지 않는다.** 같은 WiFi 에 있는 다른 사람이 남의 채팅에
이모티콘을 쏘는 것을 막는 값이다. `.gitignore` 에 들어 있다.
