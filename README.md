# 레드 응원봉

흔들면 치지직 채팅에 이모티콘이 쌓이고, 버튼을 누르면 전송되는 응원봉.
RED레드 채널 팬들에게 **무상 배포**할 목적으로 만든다 (판매·광고 없음).

```
봉(ESP32-S3) ──HTTP POST──▶ 중계 서버 ──WebSocket──▶ 크롬 확장 ──▶ 치지직 채팅
```

중계 서버는 **팬 각자의 컴퓨터에서** 돈다. 봉도 브라우저도 같은 집 안에 있으니
바깥에 서버를 둘 이유가 없다. 호스팅 비용도, 집 IP 노출도, 스트리머 PC 가 꺼지면
전부 멈추는 문제도 없다. 대신 응원봉을 쓰는 동안 팬의 컴퓨터가 켜져 있어야 한다.

> ### 📘 [설치 안내 (팬용)](docs/설치가이드.md)
> 응원봉을 받으신 분은 이쪽입니다. 비전공자 기준으로 처음부터 끝까지 적었습니다.
> 같은 내용의 웹페이지가 [`docs/설치가이드.html`](docs/설치가이드.html) 에 있습니다.
>
> 펌웨어는 **브라우저만으로** 굽습니다. 아래 주소를 열면 무엇을 구울지 이미
> 정해진 상태로 뜹니다 — `Connect` → `Flash` 두 번이면 끝입니다.
>
> [ESP Launchpad 로 굽기](https://espressif.github.io/esp-launchpad/?flashConfigURL=https://creeeeeeeeep.github.io/RED_light-stick/server/launchpad/config.toml)

## 구성

| 폴더 | 무엇 | 언어 |
|---|---|---|
| `firmware/` | 봉 펌웨어 — 모션 인식, LED, WiFi, OTA | C (ESP-IDF v5.5) |
| `server/` | 중계 서버 — **팬의 PC 에서 돈다** | Python (aiohttp) |
| `extension/` | 크롬 확장 — 채팅에 이모티콘을 넣는다 | JS (Manifest V3) |
| `docs/` | 설치 안내, 작업 기록, 치지직 조사 결과 | 문서 |
| `docs/조사/` | 치지직을 뜯어볼 때 쓴 스크립트 — **제품 코드 아님** | JS · Python |
| `modeling/` | 크라운 3D 모델 — STL 과 CadQuery 스크립트 | Python (CadQuery) |

하드웨어는 **Waveshare ESP32-S3-Matrix** (8x8 WS2812 + QMI8658 6축 IMU) 하나로,
LED와 IMU가 보드에 이미 붙어 있어 **전송 버튼만 납땜하면 된다**.

납땜하는 면(부품이 붙은 쪽)을 USB-C 가 위로 오게 두고 보면 — **LED 면에서 보면
좌우가 뒤집히니 주의** —

| 무엇 | 어디 |
|---|---|
| 전원 **5V** | 가운데 둥근 패드 |
| 전원 **GND** | 그 바로 위 둥근 패드 |
| 버튼 **SIG** | 오른쪽 열 **맨 아래 `1`** (GPIO1) |
| 버튼 **GND** | 오른쪽 열 **위에서 2번째 `G`** |

전원은 가장자리 `5V`·`G` 가 아니라 **가운데 둥근 패드**로 간다. 크고 납땜하기 쉽다.
그림은 [조립 설명서](modeling/RED_final/manual/RED_응원봉_조립설명서.pdf)의 「납땜 자리」 쪽에 있다.

크라운은 3D 프린팅한다. 현재 판은 **`modeling/RED_final/`** 이다 — 손잡이 v23 +
머리 v24, 나사 없음, 본드는 세 곳. `source/*.py` 가 형상을 만들어낸 스크립트라
치수를 고치려면 STL 이 아니라 이쪽을 고친다. 옛 판은 `modeling/old/` 에 있다.

> ### 🔧 [조립 설명서](modeling/RED_final/manual/RED_응원봉_조립설명서.pdf)
> 이케아식 10단계. 문장 대신 번호와 그림으로 되어 있다.
> 인쇄해서 봉과 같이 넣어 보내면 된다.

## 어떻게 동작하나

**모션 인식.** 가속도를 중력 방향과 그에 수직인 성분으로 나눠 좌우 흔들기 /
위아래 찍기 / 격하게 흔들기를 가른다. 보드를 어느 방향으로 넣든 중력을 매
순간 추정하므로 판정이 같다.

**이모티콘 입력.** 치지직은 채팅 입력창에 직접 넣는 것을 막는다. 그래서 확장이
**이모티콘 피커를 화면에서 감춘 채로 열어 해당 버튼을 대신 클릭한다.** 치지직이
보기에는 사용자가 직접 고른 것과 구별되지 않는다.

**전송은 사람이.** 흔들면 쌓이기만 하고, 물리 버튼을 눌러야 채팅에 나간다.
"사람의 1회 조작 = 채팅 1건" 을 지키기 위한 구조이며, 자동·주기 전송은 넣지 않는다.

**방(room) 개념이 없다.** 서버가 팬마다 자기 컴퓨터에서 도니 나눠 쓸 상대가
없기 때문이다. 봉 이벤트는 붙어 있는 확장 전부에게 간다. 확장은 `localhost`
로만 붙어서 같은 컴퓨터인 것이 증명되고, 붙으면 서버가 열쇠를 알려준다.
봉은 LAN 을 건너오므로 그 열쇠를 실어야 하는데, 설정 페이지가 대신 써넣는다.

## 시작하기

```bash
# 1. 서버 — 더블클릭으로도 된다: server/응원봉_서버_켜기.bat
cd server && py server.py

# 2. 확장 — chrome://extensions 에서 "압축해제된 확장 프로그램 로드"
#    → extension 폴더 선택

# 3. 펌웨어
cd firmware && .\crown.bat        # 인자 없이 실행하면 메뉴가 뜬다
```

`.bat` 은 파이썬과 aiohttp 를 확인해 없을 때만 설치하고 서버를 띄운다.
팬이 터미널을 열 일이 없게 하려고 둔 것이다.

봉을 굽고 나면 확장의 **옵션 페이지**를 열어 WiFi를 넣는다. 서버 주소와 열쇠는
서버가 알려주므로 직접 입력할 것이 없다 — 팬이 넣는 것은 WiFi 비밀번호뿐이다.

자세한 것은 [`firmware/README.md`](firmware/README.md) 와
[`docs/작업일지.md`](docs/작업일지.md) 를 보면 된다. 작업일지에는 **밟았던 함정**이
정리돼 있어서 같은 데서 두 번 막히지 않는다.

## 감수한 것

- **응원봉을 쓰는 동안 팬의 컴퓨터가 켜져 있어야 한다.** 서버가 거기서 돌기
  때문이다. 그 대가로 호스팅·도메인·집 IP 노출·상시 가동이 전부 사라졌다.
- **펌웨어 갱신은 손으로 한다.** OTA 코드는 남아 있지만 각자 서버에는 받아올
  펌웨어가 없어 조용히 넘어간다. 새 버전은 위 Launchpad 주소로 다시 구우면 된다.
- **WiFi 비밀번호가 봉에 평문으로 남는다.** 플래시 암호화를 아직 안 붙였다.
  **남에게 봉을 건네기 전에 반드시 지울 것** — `crown flash -Erase`, 또는
  시리얼에 `CLEAR`. Launchpad 로 구우면 NVS 가 통째로 덮여 자동으로 지워진다.

## 아직 안 된 것

- **임계값은 맨보드 기준이다.** 크라운을 달면 질량과 길이가 달라져 다시 잡아야
  한다. 손으로 할 필요는 없다 — 아래 튜닝 도구가 흔들어 본 데이터로 찾아준다.
- **플래시 암호화 없음.** 위의 평문 문제를 없애려면 이것이 필요하다.
- **펌웨어 서명 없음.** 지금은 OTA 가 각자 서버를 보는데 거기 펌웨어가 없어
  놀고 있다. 펌웨어를 한 곳에서 배포하기로 하면 그때 반드시 붙여야 한다.

## 감도 튜닝

개발자 빌드를 굽고 USB 로 연결하면 모니터 페이지가 봉의 움직임을 그대로 본다.

```bash
cd firmware && .\crown.bat flash -Dev      # 개발자 빌드 (모션 로그가 나온다)
cd server   && py server.py                 # → http://localhost:8787/monitor
```

네 가지(가만히 · 좌우 · 위아래 · 격하게)를 몇 초씩 녹음하고 **값 찾기**를 누르면,
펌웨어의 판정기를 그대로 옮긴 모의실험으로 그 녹음을 가장 잘 가르는 값을 찾는다.
동작별 정확도를 같이 보여주므로 믿을 만한지 바로 보인다.

```
봉에 적용      굽지 않고 즉시 반영된다. 흔들어서 확인
소스에 반영    server/tuning.json 에 적힌다
crown apply    gesture.c 와 board_config.h 를 대신 고친다 (고치기 전에 묻는다)
```

버튼 납땜 확인도 여기서 한다. 누르면 표시등에 불이 들어오고, 어느 핀에
납땜했는지 모르면 **핀 찾기**가 전부 훑어서 찾아준다.

## 설정 파일

`server/config.json` 은 저장소에 없다. 서버를 처음 켜면 자동으로 만들어지고,
그때 **열쇠도 함께 생성된다.** 손댈 일이 없다.

모션과 이모티콘의 짝을 바꾸고 싶을 때만 열어보면 된다.

```json
{
  "token": "(서버가 만든다)",
  "motions": {
    "SWAY_LR":  "redredMinidance1",
    "PUMP_UD":  "redredLight",
    "VIGOROUS": "redredLight5"
  }
}
```

**열쇠는 공개하지 않는다.** 같은 WiFi 에 있는 다른 사람이 남의 채팅에
이모티콘을 쏘는 것을 막는 값이다. `.gitignore` 에 들어 있다.
