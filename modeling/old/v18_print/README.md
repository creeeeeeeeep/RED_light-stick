## 스프링 — 서포트가 붙던 이유부터

v17 스프링은 **잎이 19° 경사로 올라가는 램프**였습니다.
제가 예전 README 에 "11° 라 서포트 불필요" 라고 적어놨는데 **틀린 계산이었습니다.**

```
   잎이 올라간 높이 2.4mm ÷ 잎 길이 7.0mm  →  수평에서 19°
   레이어 0.16mm 마다 안쪽으로 0.47mm 씩 허공으로 나감
   → 노즐 폭(0.4)보다 더 나가므로 슬라이서가 반드시 서포트를 붙인다
```

떼기 힘든 게 당연했고, 떼면서 0.6mm 짜리 잎이 휘어버리니 힘도 안 나왔습니다.

### 힘도 부족했습니다

```
   잎 4.0폭 × 0.6두께 × 7.0길이,  0.8mm 눌러서  →  5.0 N   (계산상)
```

계산상 5N 인데 서포트 자국 + 휨 때문에 실제로는 그 절반도 안 나왔을 겁니다.

## 고친 것 — 완전 평판 스파이럴

**두께 방향으로 경사진 부분이 하나도 없습니다.** 평평한 1.8mm 판 + 수직 원기둥 4개뿐입니다.

```
   ┌ 바깥 테두리 24.8각 (뚜껑 위에 그냥 앉음)
   │   ↘ 스파이럴 팔 4개 (75°, 폭 2.6, 두께 1.8) — 전부 같은 평면
   │       ↘ 팔 끝 패드 + 수직 기둥 Ø3.2 × 2.1  ← 보드를 여기가 민다
   └ 가운데 Ø12.2 뚫림 (배선 통로)
```

**팔이 눌리는 공간은 뚜껑이 제공합니다.** 뚜껑 윗면에 이미 있던 Ø21.2 × 1.3 릴리프
위로 팔이 떠 있어서, 0.7mm 눌려도 뚜껑에 안 닿습니다.

| | v17 | v18 |
|---|---|---|
| 형상 | 19° 램프 잎 | **완전 평판** |
| 두께 | 0.6 | **1.8** (3배) |
| 서포트 필요 면적 | 램프 전체 | **0.00 mm²** |
| 미는 힘 (계산) | 5.0 N | **13.6 N** |
| 응력 | — | 30 MPa (PLA 항복 50) — 눌러도 안 죽습니다 |

곡선 팔이라 비틀림도 같이 먹으므로 실제로는 계산보다 부드럽습니다. **체감 8~11 N** 예상.

### 힘 조절
`crown_v18.py` 위쪽에서 한 줄로 바꿉니다.

| 바꿀 값 | 효과 |
|---|---|
| `SPR_T` 1.8 → **2.0** | 힘 ×1.37 (24 N) |
| `SPR_T` 1.8 → **1.6** | 힘 ×0.70 (9.6 N) |
| `ARM_SWEEP` 75 → **65** | 힘 ×1.55 (팔이 짧아짐) |
| `ARM_SWEEP` 75 → **85** | 힘 ×0.68 |

너무 뻑뻑하면 `SPR_T` 를 1.6 으로, 더 꽉 잡고 싶으면 `ARM_SWEEP` 을 65 로.

### 밴드가 1mm 높아졌습니다
스프링이 두꺼워진 만큼 `SPR_H` 를 2.2 → **3.2** 로 올렸습니다.
보드 밑면과 스프링 테두리 사이 **1.4mm** 가 배선 통로입니다 (테두리에 0.9 깊이 홈 4개 추가).
밴드 13.8 → 14.8, 전장 130.1 → **131.1mm**.

### 스프링 출력 팁
평판이라 **인필 100% / 벽만으로** 뽑으세요 (0.68cm³ 라 어차피 금방입니다).

팔 속이 비어서 힘이 절반이 됩니다. **이게 제일 중요합니다.**

## 검증에 추가한 항목

```
── 스프링 ──
   스프링이 보드를 미는 양          :   21.29 mm3  (>0)
   스프링 ↔ 뚜껑 (안 눌린 상태)     :    0.00
   팔만 0.7mm 눌렸을 때 뚜껑에 닿나 :    0.00   ← 릴리프 충분
   아래 보는 면이 바닥 위에 있는 넓이:    0.00 mm2  ← 서포트 불필요
   가운데 배선 구멍                 : Ø 12.2 mm  (뚜껑 구멍 Ø13.4)
```

**"아래를 보는 면이 바닥면보다 위에 있는 넓이"** 를 재는 검사를 넣었습니다.
이게 0 이면 그 파트는 서포트가 필요 없습니다. v17 스프링은 여기서 걸렸을 겁니다 —
앞으로는 모든 파트에 이 검사가 돕니다.
