## v11 → v12 : 배선을 바꿨더니 손잡이가 얇아졌습니다

v11은 **커넥터가 손잡이 구멍을 통과해야** 조립이 됐습니다. 그게 굵기를 정하고 있었습니다.

| | 통과해야 하는 것 | 필요 구멍 | 손잡이 |
|---|---|---|---|
| v11 (연장 케이블) | 몰드 12.4×7.6 (대각선 14.5) | Ø15 | Ø19 |
| **v12 (직결)** | **선 6가닥** | Ø13* | **Ø17** |

\* 구멍 Ø13은 선이 아니라 **손잡이 끝 암 브레이크아웃**(11×5, 대각선 12.1)이 정합니다.

**배선**: 보드의 `5V` `GND` `GPIO19(D-)` `GPIO20(D+)` 패드에 직접 4가닥 →
손잡이 구멍을 타고 내려가 끝의 USB-C 암 브레이크아웃으로. 버튼 2가닥 추가.

덤으로 **밴드 옆 플러그 자리가 통째로 사라졌고**, 뚜껑 안 케이블 통로도 없어져
뚜껑이 4.6 → 2.6mm, 밴드가 15.0 → 13.8mm로 얇아졌습니다.

### 꼭 확인할 것
- **GPIO19·20과 5V·GND가 외부로 노출**돼 있는지 (20핀 헤더 중)
- **CC 저항** — 암 브레이크아웃에 CC1/CC2 → GND **5.1kΩ 두 개**가 있어야
  C-to-C 케이블에서 전원이 나옵니다. A-to-C만 쓸 거면 없어도 됩니다
- **D+/D- 는 짝지어서** (가능하면 꼬아서) 배선. 60mm라 USB 2.0 풀스피드엔 여유
- 펌웨어는 **조립 전에 보드 자체 USB-C로** 굽습니다

## 내부 적층이 밴드 높이를 정합니다

```
뚜껑 2.6 + 스프링 2.2 + 보드 5.5 + 걸림탭 1.6 + 돔립 1.9 = 13.8
```

스프링 높이 2.2는 **링(0.6) 위로 선이 지나갈 1.6mm**를 확보한 값입니다.
스프링 잎은 변 중앙 4곳에 있으니 **선은 모서리(45°)로** 지나가게 하세요.

**전 파트 서포트 0**을 목표로 형상을 잡았습니다 — 뿔 끝 구슬은 구가 아닌 **티어드롭**(아래 45° 원뿔),

**십자가는 반드시 눕혀서.** 세우면 층이 팔에 수직으로 쌓여 툭 치면 부러집니다.
눕히면 층이 팔과 나란해집니다. 팔 뿌리 단면 4.4×3.6 = **15.8mm²**.

## 조립

1. 보드에 먼저 **펌웨어를 굽습니다** (보드 자체 USB-C)
2. 보드 패드에 4가닥(5V/GND/19/20) 납땜. 버튼 2가닥도
3. 왕관(02)을 뒤집고 보드를 넣습니다 (LED가 아래로). 선은 모서리로 빼둡니다
4. 스프링(04)을 보드 위에 올립니다. **잎이 보드를 향하게**. 선은 링 위로
5. 선을 뚜껑(03) 중앙 구멍으로 빼면서 뚜껑을 덮습니다. 후크 2개가 딸깍
6. 왕관을 세우고 돔(01)을 **위에서** 내려 립을 빛구멍에 꽂습니다
7. 피니얼(08) → 십자가(09) 순서로 꽂습니다
8. 선을 손잡이(05) 구멍으로 통과시키고 손잡이를 뚜껑 밑에 끼웁니다
9. 암 브레이크아웃에 4가닥을 납땜하고 손잡이 끝 자리에 밀어 넣습니다
10. 택트 스위치를 버튼 자리에 넣고 뚜껑(06)을 덮습니다

접착제·나사 없음. **납땜 10군데** (보드 4 + 브레이크아웃 4 + 버튼 2).
