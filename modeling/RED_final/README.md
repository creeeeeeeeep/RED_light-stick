## 본드
- 왕관 ↔ 손잡이 (ABS끼리) : 아세톤 또는 ABS 접착제
- 돔(PETG) ↔ 왕관, 십자 ↔ 돔 : 순간접착제 또는 에폭시 (아세톤 안 먹음)

## 전자 부품
Waveshare ESP32-S3-Matrix 보드 · USB-C 끼움형 브레이크아웃(V·D−·D+·G, 5.1kΩ 내장) · 택트 스위치 6×6×5 · 가는 전선 4가닥.
**조립 전에 보드에 펌웨어를 먼저 굽는다** (조립 후엔 보드 USB 포트를 못 쓴다).

## manual/
조립 설명서 — 이케아식. 문장 대신 번호 · 글자 · 화살표 · 기호로 말한다.
글자는 틀리면 다치는 곳에만 남겼다 (배선, 전선 길이, 돌리는 각도).

| 파일 | 무엇 |
|---|---|
| `RED_응원봉_조립설명서.pdf` | 인쇄용 A4. 같이 넣어 보내는 것 |
| `RED_응원봉_조립설명서.html` | 같은 내용의 웹페이지 |
| `설명서_짓기.py` | HTML 을 짓는다. 고칠 일이 있으면 여기를 고치고 다시 실행 |
| `그림원본.html` | 선 그림 24장이 들어 있는 옛 설명서. 그림을 여기서 꺼내 쓴다 |

```bash
cd manual && py 설명서_짓기.py        # HTML 다시 짓기
```

PDF 는 크롬으로 뽑는다 (헤더·푸터 없이 A4):

```bash
chrome --headless --no-pdf-header-footer --print-to-pdf=RED_응원봉_조립설명서.pdf RED_응원봉_조립설명서.html
```
