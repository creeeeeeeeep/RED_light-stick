개인정보처리방침 — 크라운 응원봉

시행일: 2026-11-01

1. 수집하는 정보

없습니다. 이 확장 프로그램은 개인정보, 사용 기록, 채팅 내용, 접속 정보 등 어떤 데이터도 수집하거나 저장하지 않으며, 개발자를 포함한 누구에게도 전송하지 않습니다.

2. 브라우저에 저장되는 정보

다음 값이 chrome.storage.local 에 저장됩니다. 사용자의 브라우저 안에만 있으며, 확장 프로그램을 삭제하면 함께 지워집니다.

값용도
중계 프로그램 주소연결할 주소 (ws://localhost:8787/ws)
설치본 식별자무작위 문자열. 브라우저를 여러 번 재연결할 때 중복 연결을 정리하는 데만 쓰입니다.
대상 탭 선택치지직 탭이 여러 개일 때 사용자가 고른 탭 (브라우저를 닫으면 사라집니다)

3. 네트워크 통신

이 확장 프로그램이 통신하는 곳은 두 군데뿐입니다.

대상무엇을
localhost (사용자 컴퓨터) 사용자 컴퓨터에서 실행 중인 중계 프로그램에 연결합니다. 응원봉을 흔들거나 버튼을 눌렀다는 신호만 전달받습니다. 같은 컴퓨터 안에서만 이루어지며 인터넷으로 나가지 않습니다.
api.chzzk.naver.com 현재 보고 있는 채널에서 쓸 수 있는 이모티콘 목록을 조회합니다. 구독 전용이라 사용할 수 없는 이모티콘을 미리 걸러내기 위한 것으로, 치지직 웹사이트가 사용하는 것과 같은 공개 API 입니다. 이 요청에는 브라우저가 이미 보유한 치지직 로그인 쿠키가 포함되며(구독 여부 확인에 필요합니다), 응답은 메모리에서만 쓰이고 저장되지 않습니다.

그 외 어떤 서버와도 통신하지 않습니다. 분석 도구, 광고, 외부 추적 코드를 포함하지 않습니다.

4. 치지직 페이지에서 하는 일

응원봉 신호를 받으면 치지직의 이모티콘 선택창을 열어 해당 이모티콘 버튼을 클릭합니다. 사용자가 직접 고르는 것과 같은 경로입니다.

입력이 제대로 들어갔는지 확인하기 위해 채팅 입력창에 들어 있는 이모티콘의 개수를 셉니다. 채팅 내용을 읽어 저장하거나 외부로 보내지 않으며, 다른 사람의 채팅이나 페이지의 다른 요소에는 접근하지 않습니다.

채팅 전송은 사용자가 응원봉의 물리 버튼을 눌렀을 때만 일어납니다. 자동으로 또는 주기적으로 전송하는 기능은 없습니다.

Privacy Policy (English)

No data is collected. This extension does not collect, store, or transmit personal information, usage data, or chat content to anyone, including the developer.

Local storage. The relay address, a random install identifier, and the selected tab are kept in chrome.storage.local on the user's own browser and are removed when the extension is uninstalled.

Network. The extension connects only to (1) a relay program running on the user's own computer via localhost, which forwards shake and button signals from a WiFi-connected light-stick device, and (2) api.chzzk.naver.com to list the emoticons available on the current channel. The latter uses the browser's existing CHZZK session cookie to determine subscription status; the response is used in memory only. No other servers are contacted. No analytics, ads, or tracking are included.

On CHZZK pages. The extension opens the site's own emoticon picker and clicks the requested emoticon, the same path a user takes manually. It counts the emoticons present in the chat input box to confirm the insertion succeeded; it does not read or store chat content. Messages are sent only when the user presses the physical button on the device. There is no automatic or scheduled sending.

Source. The full source is public at github.com/creeeeeeeeep/RED_light-stick.
