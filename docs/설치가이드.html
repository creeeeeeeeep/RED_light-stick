RED레드 응원봉

처음 한 번만 하면 됩니다

흔들면 채팅에 이모티콘이 쌓이고, 버튼을 누르면 전송됩니다. 설정은 20분이면 끝나고, 그 뒤로는 전원만 연결하면 됩니다.

준비물

  • 응원봉
  • 데이터 전송용 USB 케이블 — 충전만 되는 건 안 됩니다
  • 크롬 브라우저가 깔린 컴퓨터 — 응원봉을 쓰는 동안 켜져 있어야 합니다
브라우저

크롬과 엣지만 됩니다. 사파리와 파이어폭스에는 응원봉을 연결하는 기능이 아예 없습니다.

1

파일 내려받기

아래 주소를 열고, 초록색 < > Code 버튼 → Download ZIP 을 누릅니다.

github.com/creeeeeeeeep/RED_light-stick

내려받은 파일에 오른쪽 클릭 → 압축 풀기 를 합니다.

여기서 자주 막힙니다

윈도우는 압축 파일을 폴더처럼 열어줍니다. 하지만 그건 진짜 폴더가 아니라서 크롬이 읽지 못합니다. 반드시 압축을 푸세요.

풀고 나면 이런 폴더들이 보입니다. 이 위치를 기억해 두세요.

RED_light-stick-main/ ├── extension/ ← 2번에서 씁니다 ├── server/ ← 3번, 4번에서 씁니다 ├── firmware/ └── docs/
2

확장 프로그램 설치

크롬 주소창에 아래를 붙여넣고 엔터를 칩니다.

chrome://extensions

오른쪽 위의 개발자 모드 스위치를 켭니다. 켜면 왼쪽 위에 버튼이 새로 나타납니다.

그중 압축해제된 확장 프로그램을 로드합니다 를 누르고, 아까 압축 푼 곳의 extension 폴더를 선택합니다.

주의

폴더 안의 파일이 아니라 폴더 자체를 고르는 것입니다. extension 을 한 번 클릭해 선택한 상태로 폴더 선택 을 누르세요.

크라운 응원봉 카드가 생기면 성공입니다.

주소창 오른쪽의 퍼즐 조각 아이콘을 누르고 크라운 응원봉 옆의 핀을 눌러 두면 툴바에 항상 보입니다. 나중에 상태를 확인할 때 편합니다.

이런 게 떠도 괜찮습니다

“개발자 모드 확장 프로그램을 사용 중지하세요” 안내가 나오면 취소 를 누르세요. 웹스토어에 정식 등록되기 전까지는 계속 나옵니다.

3

서버 켜기

응원봉과 브라우저는 서로 직접 말을 못 합니다. 사이에서 말을 전해줄 프로그램이 하나 필요한데, 그게 여러분 컴퓨터에서 돕니다. 인터넷 어딘가가 아니라 집 안에서만 돌기 때문에 흔든 기록이 밖으로 나가지 않습니다.

서버·응원봉·브라우저가 전부 한 집 안에 있어서, 계정도 가입도 없습니다.

압축 푼 폴더의 server 안에 있는 파일을 더블클릭합니다.

server / 응원봉_서버_켜기.bat

처음 한 번은 1분쯤 걸립니다. 필요한 것을 받아오기 때문입니다.

파이썬이 없다고 나오면

안내에 뜬 주소에서 받아 설치하세요. 설치 화면 맨 아래 Add Python to PATH 를 꼭 체크해야 합니다. 설치 후 파일을 다시 더블클릭하면 됩니다.

python.org/downloads

방화벽 창이 뜨면

반드시 액세스 허용 을 누르세요. 개인 네트워크에 체크가 되어 있어야 합니다. 여기서 차단하면 응원봉이 컴퓨터를 찾지 못합니다.

이렇게 뜨면 켜진 것
—
응원봉 서버가 켜졌습니다.
—
이 창을 닫으면 서버도 꺼집니다.

이 창은 닫지 마세요. 최소화해 두시면 됩니다. 응원봉을 쓸 때마다 이 파일을 더블클릭해서 켜야 합니다.

4

응원봉에 펌웨어 굽기

건너뛰어도 되는 경우

응원봉을 이미 설정된 상태로 받으셨다면 이 단계는 필요 없습니다. 바로 5번으로 가세요.

USB 케이블로 응원봉을 컴퓨터에 연결합니다. 드라이버는 따로 깔지 않아도 됩니다.

크롬에서 아래 주소를 엽니다.

espressif.github.io/esp-launchpad

위쪽 탭에서 DIY 를 누르고, Connect 를 누릅니다. 기기를 고르는 창이 뜨면 USB JTAG/serial debug unit 같은 이름을 선택합니다.

목록이 비어 있다면

케이블이 충전 전용일 가능성이 큽니다. 이게 가장 흔한 원인입니다. 휴대폰에 연결했을 때 사진·파일이 보이는 케이블로 바꿔보세요.

연결되면 플래시 주소 칸이 여러 줄 나옵니다. 한 줄만 남기고 나머지는 오른쪽 ✕ 로 지웁니다. 남은 줄을 이렇게 채웁니다.

플래시 주소파일
0x0 server / launchpad / cheerstick-0.8.0-merged.bin
숫자를 꼭 고치세요

처음에 0x1000 이라고 적혀 있습니다. 그건 다른 기종용 값이라 그대로 두면 응원봉이 켜지지 않습니다. 0x0 으로 바꾸세요.

프로그램 을 누르면 1분쯤 걸립니다. 진행 막대가 끝까지 가고 멈추면 완료이고, 응원봉에 불이 들어옵니다.

플래시 지우기 는 누르지 않아도 됩니다.

5

WiFi 연결하기

응원봉은 USB에 연결한 채로 두세요.

chrome://extensions 에서 크라운 응원봉 카드의 세부정보 → 확장 프로그램 옵션 을 누르면 설정 페이지가 열립니다.

봉 연결하기 를 누르고 기기를 선택합니다. 3번에서 했던 것과 같습니다. 연결되면 주변 WiFi를 자동으로 찾습니다.

목록에서 집 WiFi를 고르고 비밀번호를 넣습니다.

5GHz는 안 됩니다

응원봉은 2.4GHz만 지원합니다. 공유기 이름이 우리집_5G 처럼 끝난다면, 5G가 없는 쪽을 고르세요. 목록에 안 보이면 다시 검색 을 눌러보세요.

서버 주소는 저절로 채워집니다. 3번에서 켜 둔 서버가 자기 주소를 알려주기 때문입니다. 응원봉에 넣을 열쇠도 서버가 만들어 대신 써넣습니다.

여기서 입력하실 것은 없습니다. 이 설정 전체에서 직접 치시는 건 WiFi 비밀번호 하나뿐입니다.

칸이 비어 있다면

서버가 안 켜져 있는 것입니다. 3번으로 돌아가 창이 떠 있는지 확인하세요.

마지막으로 봉에 저장하기 를 누릅니다. 잠시 뒤 아래 상태 칸이 이렇게 바뀌면 성공입니다.

여기까지 하면 USB를 뽑아도 됩니다. 응원봉이 WiFi 설정을 기억하므로, 다음부터는 전원만 연결하면 알아서 붙습니다.

6

흔들어 보기

치지직에서 RED레드 방송에 들어갑니다. 툴바의 크라운 아이콘을 누르면 지금 상태가 보입니다.

이제 응원봉을 흔들어 보세요.

  • 좌우로 흔들기 — 빨간 불이 숨쉬듯 일렁입니다
  • 위아래로 찍기 — 무지개가 천천히 흐릅니다
  • 격하게 흔들기 — 금빛으로 쿵쿵 터집니다

1초에 하나씩 쌓이고, 채팅창에는 최대 10개까지 들어갑니다.

쌓인 것을 보내려면 응원봉의 버튼을 누릅니다. 흔드는 것만으로는 채팅이 나가지 않습니다 — 보내는 순간은 항상 본인이 정합니다.

알아두시면 좋은 것

응원봉은 충전기나 보조배터리에 꽂아도 됩니다. 컴퓨터에 USB로 연결할 일은 설정할 때뿐이고, 보조배터리에 물리면 오히려 더 밝아집니다.

다만 컴퓨터는 켜져 있어야 하고 서버 창도 열려 있어야 합니다. 말을 전해주는 게 그 프로그램이라, 꺼지면 흔들어도 채팅에 들어가지 않습니다.

새 버전이 나오면 다시 구우셔야 합니다. 파일을 새로 받아 3번(굽기)과 4번(WiFi)을 다시 하시면 됩니다.

따뜻해지는 건 정상입니다. LED 64개가 켜져 있어서 그렇습니다. 다만 손에 쥐기 불편할 만큼 뜨거우면 사용을 멈추고 알려주세요.

이 응원봉은 팬에게 무상으로 나누는 것이며 판매하지 않습니다. 소스와 자세한 설명은 깃허브 저장소에 있습니다.
