# 응원봉 설치 안내

처음 한 번만 하면 됩니다. **20분쯤** 걸립니다.

준비물은 세 가지입니다.

- 응원봉
- **데이터 전송용** USB 케이블 — 충전만 되는 케이블은 안 됩니다
- 크롬 브라우저가 깔린 컴퓨터 (윈도우 / 맥 둘 다 됩니다)

> **엣지 브라우저도 됩니다.** 사파리와 파이어폭스는 안 됩니다.
> 봉을 컴퓨터에 연결하는 기능이 그 두 브라우저에는 없습니다.

순서는 이렇습니다.

1. [파일 내려받기](#1-파일-내려받기)
2. [확장 프로그램 설치](#2-확장-프로그램-설치)
3. [서버 켜기](#3-서버-켜기)
4. [응원봉에 펌웨어 굽기](#4-응원봉에-펌웨어-굽기)

## 1. 파일 내려받기

<https://github.com/creeeeeeeeep/RED_light-stick> 로 갑니다.

초록색 **`< > Code`** 버튼을 누르고 → **`Download ZIP`** 을 누릅니다.

내려받은 `RED_light-stick-main.zip` 을 **압축 풉니다.**

> **꼭 압축을 푸셔야 합니다.** 윈도우는 압축 파일을 폴더처럼 열어주는데,
> 그건 진짜 폴더가 아니라 크롬이 읽지 못합니다.
>
> 압축 파일에 오른쪽 클릭 → **압축 풀기** 를 누르세요.

풀고 나면 이런 폴더들이 보입니다. 이 위치를 기억해 두세요.

```
RED_light-stick-main/
├── extension/     ← 2번에서 씁니다
├── server/        ← 3번에서 씁니다
├── firmware/
└── docs/
```

## 2. 확장 프로그램 설치

크롬 주소창에 아래를 **복사해서 붙여넣고** 엔터를 칩니다.

```
chrome://extensions
```

**오른쪽 위**에 **`개발자 모드`** 스위치가 있습니다. **켭니다.**

켜면 **왼쪽 위**에 버튼 세 개가 새로 나타납니다. 그중
**`압축해제된 확장 프로그램을 로드합니다`** 를 누릅니다.

폴더를 고르는 창이 뜹니다. 아까 압축 푼 곳으로 가서
**`extension` 폴더를 선택**합니다.

> **폴더를 선택하는 것**이지 그 안의 파일을 고르는 게 아닙니다.
> `extension` 폴더를 한 번 클릭해서 선택한 상태로 **폴더 선택** 을 누르세요.

**"크라운 응원봉"** 이라는 카드가 생기면 성공입니다.

### 툴바에 고정해 두기

주소창 오른쪽의 **퍼즐 조각 아이콘**을 누르면 설치된 확장 목록이 나옵니다.
**"크라운 응원봉"** 옆의 **핀 아이콘**을 눌러 두면 툴바에 항상 보입니다.
나중에 상태를 확인할 때 편합니다.

> **"개발자 모드 확장 프로그램을 사용 중지하세요"** 라는 안내가 뜰 수 있습니다.
> **`취소`** 를 누르면 됩니다. 크롬 웹스토어에 올라가기 전까지는 계속 뜹니다.

## 3. 서버 켜기

응원봉과 브라우저는 서로 직접 말을 못 합니다. 사이에서 말을 전해줄 프로그램이
하나 필요한데, 그게 **여러분 컴퓨터에서 돕니다.** 인터넷 어딘가가 아니라
집 안에서만 돌기 때문에, 흔든 기록이 밖으로 나가지 않습니다.

압축 푼 폴더의 **`server`** 안에 있는 파일을 더블클릭합니다.

```
RED_light-stick-main/server/응원봉_서버_켜기.bat
```

**처음 한 번은 1분쯤** 걸립니다. 필요한 것을 받아오기 때문입니다.

> **파이썬이 없다고 나오면** — 안내에 뜬 주소에서 받아 설치하세요.
> 설치 화면 맨 아래 **`Add Python to PATH`** 를 **꼭 체크**해야 합니다.
> 설치 후 `.bat` 파일을 다시 더블클릭하면 됩니다.
>
> <https://www.python.org/downloads/>

> **윈도우 방화벽 창이 뜨면 반드시 `액세스 허용`** 을 누르세요.
> **`개인 네트워크`** 에 체크가 되어 있어야 합니다.
> 여기서 차단하면 응원봉이 컴퓨터를 찾지 못합니다.

이런 화면이 나오면 켜진 것입니다.

```
============================================================

  응원봉 서버가 켜졌습니다.

  이 창을 닫으면 서버도 꺼집니다.
  응원봉을 쓰는 동안에는 열어 두세요.

============================================================
```

**이 창은 닫지 마세요.** 최소화해 두시면 됩니다. 응원봉을 쓸 때마다
이 파일을 더블클릭해서 켜야 합니다.

## 4. 응원봉에 펌웨어 굽기

> 응원봉을 이미 설정된 상태로 받으셨다면 **이 단계는 건너뛰세요.**
> 바로 [5번](#5-wifi-연결하기)으로 가시면 됩니다.

**USB 케이블로 응원봉을 컴퓨터에 연결합니다.** 드라이버를 따로 깔 필요는 없습니다.

크롬에서 아래 주소를 엽니다.

```
https://espressif.github.io/esp-launchpad/
```

### 4-1. 연결하기

위쪽 탭에서 **`DIY`** 를 누릅니다.

**`Connect`** 버튼을 누르면 **기기를 고르는 창**이 뜹니다.
`USB JTAG/serial debug unit` 같은 이름이 보이면 그걸 선택하고 **연결**을 누릅니다.

> **목록이 비어 있다면** — 케이블이 충전 전용일 가능성이 큽니다.
> 다른 케이블로 바꿔보세요. 이게 가장 흔한 원인입니다.

### 4-2. 파일 지정하기

**`플래시 주소`** 칸이 여러 줄 나옵니다. **한 줄만 남기고 나머지는
오른쪽 `✕` 로 지웁니다.**

남은 한 줄을 이렇게 채웁니다.

| 플래시 주소 | 파일 |
|---|---|
| **`0x0`** | `server/launchpad/cheerstick-0.8.0-merged.bin` |

**주소를 반드시 `0x0` 으로 고치세요.** 처음에 `0x1000` 이라고 적혀 있는데
그건 다른 기종용 값입니다.

파일은 **`파일 선택`** 을 눌러 아까 압축 푼 폴더 안에서 찾습니다.

```
RED_light-stick-main/server/launchpad/cheerstick-0.8.0-merged.bin
```

### 4-3. 굽기

**`프로그램`** 버튼을 누릅니다. 1분쯤 걸립니다.

> **`플래시 지우기` 는 누르지 마세요.** 필요 없습니다.

진행 막대가 끝까지 가고 멈추면 완료입니다. **응원봉에 불이 들어옵니다.**

## 5. WiFi 연결하기

**응원봉은 USB로 연결한 채로** 두세요.

`chrome://extensions` 에서 **"크라운 응원봉"** 카드의
**`세부정보`** → **`확장 프로그램 옵션`** 을 누릅니다.

설정 페이지가 열립니다. 순서대로 하시면 됩니다.

### 1단계 — 봉 연결하기

**`봉 연결하기`** 를 누르고, 뜨는 창에서 기기를 골라 연결합니다.
3번에서 했던 것과 같습니다.

연결되면 **`연결됨`** 이라고 바뀌고, 주변 WiFi를 자동으로 찾기 시작합니다.

### 2단계 — WiFi

**네트워크** 목록에서 집 WiFi를 고르고 **비밀번호**를 넣습니다.

> **5GHz WiFi는 안 됩니다.** 응원봉은 2.4GHz만 지원합니다.
> 공유기 이름이 `우리집_5G` 처럼 끝난다면 `5G` 가 없는 쪽을 고르세요.
>
> 목록에 없으면 **`다시 검색`** 을 눌러보세요.

### 3단계 — 서버

**아무것도 안 하셔도 됩니다.** 3번에서 켜 둔 서버가 자기 주소를 알려주므로
**서버 주소 칸이 저절로 채워집니다.**

```
서버 주소   http://192.168.0.42:8787
```

방 코드와 열쇠도 자동으로 만들어집니다.

> **칸이 비어 있다면** 서버가 안 켜져 있는 것입니다.
> [3번](#3-서버-켜기)으로 돌아가 창이 떠 있는지 확인하세요.

### 4단계 — 저장

**`봉에 저장하기`** 를 누릅니다.

아래 **상태** 칸이 잠시 뒤 이렇게 바뀌면 성공입니다.

```
봉        연결됨
WiFi      우리집WiFi   192.168.0.42
서버      http://192.168.0.42:8787
방        서버 연결됨
```

**여기까지 하면 USB를 뽑아도 됩니다.** 응원봉이 WiFi 설정을 기억하기 때문에,
다음부터는 **전원만 연결하면** 알아서 붙습니다.

## 6. 잘 되는지 확인

치지직에서 **RED레드 방송에 들어갑니다.**

툴바의 **크라운 응원봉 아이콘**을 누르면 상태가 보입니다.

```
봉: 연결됨  192.168.0.42  v0.8.0  3분째
자동 선택: RED레드 ...
```

이제 **응원봉을 흔들어 보세요.**

- **좌우로 흔들기** → 빨간 불, 채팅창에 이모티콘이 하나씩 쌓입니다
- **위아래로 찍기** → 무지개 불
- **격하게 흔들기** → 금빛으로 번쩍입니다

**1초에 하나씩** 쌓이고, 채팅창에 최대 10개까지 들어갑니다.

쌓인 걸 보내려면 **응원봉의 버튼을 누릅니다.** 흔드는 것만으로는 채팅이
나가지 않습니다 — 보내는 건 항상 본인이 결정합니다.

## 잘 안 될 때

### 응원봉이 목록에 안 뜹니다

**케이블을 의심하세요.** 충전 전용 케이블이 가장 흔한 원인입니다.
휴대폰에 연결했을 때 **파일이 보이는** 케이블이어야 합니다.

다른 프로그램이 응원봉을 잡고 있어도 안 뜹니다. **설정 페이지를 여러 개
열어두지 마세요.** 하나만 남기고 닫은 뒤 다시 해보세요.

### WiFi에 연결이 안 됩니다

- **5GHz를 고르셨을 가능성이 큽니다.** 2.4GHz를 고르세요.
- 비밀번호를 다시 확인하세요. **`비밀번호 표시`** 를 체크하면 보입니다.
- 공유기에서 너무 멀면 못 붙습니다. 가까이서 한 번 해보세요.

### 흔들어도 채팅에 안 들어갑니다

**먼저 서버 창이 열려 있는지 보세요.** 실수로 닫았거나 컴퓨터를 재시작하면
꺼져 있습니다. [3번](#3-서버-켜기)의 파일을 다시 더블클릭하면 됩니다.

그다음 **치지직 탭을 새로고침(F5)** 해보세요. 이 둘로 대부분 해결됩니다.

그래도 안 되면 확장 아이콘을 눌러 상태를 봅니다.

| 보이는 것 | 뜻 |
|---|---|
| `봉: 끊김` | 응원봉이 꺼졌거나 WiFi가 끊겼습니다 |
| `서버에 연결할 수 없습니다` | 서버 창이 꺼져 있습니다 |
| `치지직 탭이 없습니다` | 방송 페이지를 열어주세요 |
| `치지직 탭이 3개입니다` | **`이 탭을 대상으로`** 를 눌러 하나를 정하세요 |

**로그인은 되어 있어야 합니다.** 그리고 구독자 전용 이모티콘은
구독 중인 계정에서만 들어갑니다.

### 불은 들어오는데 아무 일도 없습니다

WiFi 설정이 안 된 상태입니다. [5번](#5-wifi-연결하기)을 다시 해보세요.

### 그래도 안 되면

응원봉을 다시 구우면 대부분 해결됩니다. [4번](#4-응원봉에-펌웨어-굽기)을
다시 하시면 되고, **WiFi 설정은 지워지므로 5번도 다시** 하셔야 합니다.

## 알아두시면 좋은 것

**응원봉은 충전기나 보조배터리에 꽂아도 됩니다.** 컴퓨터에 USB로 연결할 일은
설정할 때뿐입니다. 보조배터리에 물리면 오히려 더 밝아집니다.

**다만 컴퓨터는 켜져 있어야 하고, 서버 창도 열려 있어야 합니다.**
말을 전해주는 게 그 프로그램이라, 꺼지면 흔들어도 채팅에 안 들어갑니다.

**새 버전이 나오면 다시 구우셔야 합니다.** 파일을 새로 받아
[4번](#4-응원봉에-펌웨어-굽기)을 다시 하시면 됩니다. WiFi 설정이 지워지므로
[5번](#5-wifi-연결하기)도 이어서 하셔야 합니다.

**따뜻해지는 건 정상입니다.** LED 64개가 켜져 있어서 그렇습니다.
다만 손에 쥐기 불편할 만큼 뜨거우면 사용을 멈추고 알려주세요.
