# 조사 스크립트

치지직이 이모티콘을 어떻게 다루는지 알아내려고 쓴 것들이다. **제품 코드가
아니다** — 확장이나 서버가 이 파일들을 불러 쓰지 않는다.

남겨 두는 이유는 하나다. "왜 이렇게 만들었나" 의 근거가 여기 있다. 나중에
치지직이 바뀌어 확장이 깨지면, 처음부터 다시 알아내는 대신 이걸 다시 돌려
무엇이 달라졌는지 보면 된다.

| 파일 | 무엇을 알아내려고 |
|---|---|
| `picker-probe.js` | 이모티콘 피커의 DOM 구조와 클릭 경로 |
| `input-probe.js` | 채팅 입력창이 들고 있는 상태 |
| `input-insert.js` | 입력창에 직접 넣어 보려던 시도들 (전부 실패) |
| `state-probe.js` | 리액트 state 에 직접 넣어 보려던 시도 |
| `ws-capture.js` | 실제 전송 프레임 캡처 |
| `emoji_test.py` | 공식 API 로 이모티콘을 보낼 수 있는지 (불가 확인) |

결론은 [`../emoji-reference.md`](../emoji-reference.md) 에 정리돼 있다.
요약하면 **입력창에 직접 넣는 길은 전부 막혀 있고, 피커를 열어 버튼을
대신 클릭하는 것만 통한다.**

브라우저 콘솔에 붙여넣어 쓰는 것들이라 그대로 실행되지 않을 수 있다.
