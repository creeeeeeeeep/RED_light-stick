크라운 응원봉 설정

봉을 USB로 연결하고 아래 순서대로 진행하세요. 한 번만 하면 됩니다.

1 봉 연결

USB 케이블로 봉을 연결한 뒤 아래 버튼을 누르세요. 크롬/엣지에서만 됩니다.

연결 안 됨

2 WiFi

봉이 인터넷에 붙어야 흔든 신호가 전달됩니다. 가능하면 게스트 WiFi를 쓰세요 — 봉이 집 안 다른 기기에 접근하지 못합니다.

3 서버

봉이 신호를 보낼 주소입니다. 방 코드는 자동으로 만들어지고 확장에도 같이 저장되므로 직접 입력할 필요가 없습니다.

서버는 이 컴퓨터에서 돕니다. 주소와 열쇠는 서버가 알려주므로 직접 적을 것이 없습니다.

4 저장

봉과 확장에 같은 설정을 한 번에 기록합니다.

상태

한 번 저장하면 봉이 스스로 기억합니다. 다음부터는 전원만 넣으면 알아서 WiFi 에 붙으니 이 페이지를 다시 열 필요가 없습니다.

밝기 직접 정하기

봉은 어디에 꽂혔는지 보고 스스로 정합니다 — PC면 낮게, 충전기면 높게. 전압이 주저앉아 재부팅되면 한 단계 내려 기억하므로 보통은 그냥 두시면 됩니다. 직접 올리실 거면 발열을 확인하세요. 손에 쥐기 불편할 정도면 낮추는 게 맞습니다.

준비되었습니다.
알아두실 것. WiFi 비밀번호는 봉 안에 저장됩니다. 배포용 봉은 플래시 암호화를 켜서 꺼내볼 수 없게 하지만, 개발용 보드는 그렇지 않으니 실제 집 WiFi 비밀번호를 넣을 때 유의하세요.
