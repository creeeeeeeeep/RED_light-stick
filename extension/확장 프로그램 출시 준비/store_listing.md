# 크롬 웹스토어 리스팅 자료

대시보드에 그대로 붙여넣는 용도. **적힌 내용이 실제 동작과 일치해야 한다** —
설명과 권한이 어긋나면 심사에서 거절되거나 등록 후에 내려간다.

## 2. 상세 설명 (붙여넣기용)

```
팬메이드 응원봉(ESP32)과 함께 쓰는 확장 프로그램입니다.
응원봉 없이는 아무 기능도 하지 않습니다.

■ 하는 일
응원봉을 흔들면 치지직 채팅 입력창에 이모티콘이 하나씩 채워집니다.
채팅으로 전송되는 것은 사용자가 응원봉의 물리 버튼을 눌렀을 때뿐입니다.

■ 자동 전송이 없습니다
흔드는 동작은 '입력'만 합니다. '전송'은 반드시 사람이 버튼을 눌러야 합니다.
사람의 조작 1회가 채팅 1건에 대응하며, 주기적·자동 전송 기능은 없습니다.

■ 동작하려면 세 가지가 필요합니다
 1. 응원봉 (같은 WiFi 에 연결)
 2. 사용자 컴퓨터에서 실행하는 중계 프로그램
 3. 이 확장 프로그램

응원봉과 브라우저는 서로 직접 통신할 수 없기 때문에, 사용자 컴퓨터에서
중계 프로그램이 돌아갑니다. 이 프로그램은 사용자의 집 네트워크 안에서만
동작하며 인터넷으로 나가지 않습니다.
설치 방법: https://github.com/creeeeeeeeep/RED_light-stick

■ 이모티콘을 넣는 방식
치지직 화면의 이모티콘 선택창을 열어 해당 버튼을 클릭합니다.
사용자가 직접 고르는 것과 같은 경로이며, 채팅 프로토콜을 직접 다루지 않습니다.

■ 수집하는 정보
없습니다. 사용 기록이나 채팅 내용을 수집하거나 외부로 보내지 않습니다.
설정값(중계 프로그램 주소)은 브라우저 안에만 저장됩니다.

■ 소스 공개
전체 소스가 공개되어 있습니다.
https://github.com/creeeeeeeeep/RED_light-stick
```

## 3. 권한 사유 (대시보드 입력란)

심사에서 **권한마다 따로 묻는다.** 아래를 그대로 붙여넣으면 된다.

| 권한 | 사유 (붙여넣기) |
|---|---|
| `storage` | `중계 프로그램의 주소와 사용 여부를 저장합니다. 브라우저 안에만 저장되며 외부로 전송하지 않습니다.` |
| `tabs` | `치지직 방송 탭이 여러 개 열려 있을 때 어느 탭에 이모티콘을 넣을지 사용자가 고를 수 있도록, 열린 치지직 탭의 제목을 읽습니다.` |
| `alarms` | `중계 프로그램과의 연결이 끊어졌는지 1분마다 확인해 다시 연결합니다. 서비스 워커가 종료되어도 연결이 복구되도록 하기 위한 것입니다.` |
| `https://chzzk.naver.com/*` | `이 확장의 기능 자체가 치지직 채팅창에 이모티콘을 넣는 것입니다. 해당 페이지에서만 동작합니다.` |
| `https://api.chzzk.naver.com/*` | `현재 채널에서 사용할 수 있는 이모티콘 목록을 조회합니다. 구독 전용이라 사용할 수 없는 이모티콘을 미리 걸러내기 위한 것으로, 치지직 웹사이트가 사용하는 것과 같은 공개 API 입니다.` |
| `http://localhost/*` | `사용자 컴퓨터에서 실행 중인 중계 프로그램에 연결합니다. 응원봉은 WiFi 기기라 브라우저와 직접 통신할 수 없어, 사용자 컴퓨터 안에서 도는 프로그램이 신호를 전달합니다. localhost 외부와는 통신하지 않습니다.` |

**원격 코드 사용 여부:** 아니요 (모든 코드가 패키지에 포함됨)

## 5. 스크린샷 (1280×800, 1~5장)

실제 화면으로 찍는다. 추천 구성:

1. **치지직 채팅창에 이모티콘이 쌓인 모습** — 이 확장이 뭘 하는지 한 장으로 보여준다
2. **확장 설정 페이지** — 응원봉 연결 / WiFi / 상태판
3. **팝업** — 봉 상태와 대상 탭
4. **응원봉 실물** — 흔드는 모습이나 LED 가 켜진 모습

> 1번이 제일 중요하다. 심사자가 "이게 무슨 확장인지" 를 여기서 판단한다.

## 7. 심사에서 물어볼 만한 것

**"채팅 자동화 아닌가?"**
자동 전송이 없다는 점을 설명에 먼저 적어 두었다. 흔들기는 입력창을 채울 뿐이고,
전송은 사용자가 물리 버튼을 눌러야 일어난다. 소스가 공개돼 있어 확인할 수 있다.

**"localhost 권한이 왜 필요한가?"**
응원봉은 WiFi 기기라 브라우저와 직접 통신할 수 없다. 사용자 컴퓨터에서 도는
중계 프로그램이 신호를 전달하고, 확장은 거기에 붙는다.

**"MAIN 월드 콘텐츠 스크립트를 왜 쓰는가?"**
치지직의 이모티콘 목록 API 를 페이지와 같은 자격으로 조회하기 위해서다.
그 외에 페이지 스크립트를 가로채거나 바꾸지 않는다.

**심사 기간은 보통 며칠이다.** 거절되면 사유가 메일로 오고, 고쳐서 다시 올리면 된다.
